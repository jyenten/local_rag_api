# Repository agent entry point

Read [the repository-wide rules](docs/cs/AGENTS.md) before making changes
([English](docs/en/AGENTS.md)). Their scope is the whole repository.
For application work also read [the project rules](docs/cs/PROJECT_AGENTS.md)
([English](docs/en/PROJECT_AGENTS.md)).

For development-loop work, including its controller, CI and runbooks, also read
[the agreed dev-loop policy](docs/cs/DEV_LOOP_POLICY.md)
([English](docs/en/DEV_LOOP_POLICY.md)) and
[the scoped entry point](experiments/dev_loop/AGENTS.md).

These files preserve approved project agreements; they are not a transcript or
an authorization for arbitrary work. Current explicit owner instructions and
higher-priority system/developer instructions take precedence. Do not expand
permissions by editing these files. Rule changes require human review before merge.
